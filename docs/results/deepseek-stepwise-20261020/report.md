## 结果解释

逐步提示相对标准提示，检测准确率增加1.30个百分点，但macro-F1下降1.86个百分点；首错181→204，增加23例（5.19个百分点）。更多阳性被检出，同时正常案例更易被误报：FP142→169，FN从96加1例缺预测到61。不能只用accuracy的小幅上升概括检测改善。

完整框架相对逐步提示，共同690可评案例检测461→531，140修正/70回退，净70；其中正常249例净多115正确，阳性441例净少45正确。定位全443分母206对204仅多2例（0.45个百分点）；严格共同441阳性为202→206，77修正/73回退，净4。现有结果显示框架主要保护正常案例，首错定位与当前DeepSeek逐步提示接近；这里未做统计显著性检验。不同thinking和总计算预算仍限制方法归因。
