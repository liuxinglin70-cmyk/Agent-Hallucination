# Reference Papers

This directory indexes reference papers and framework-design notes.  The
paper files themselves are large and are kept locally in `Paper/` (git-ignored).

## Index

Add one entry per paper:

```text
- Title
  - Author(s)
  - Year
  - Local file: Paper/<name>.pdf
  - Relevance: one-line summary of how it informs the detector or the
    self-evolution framework
```
