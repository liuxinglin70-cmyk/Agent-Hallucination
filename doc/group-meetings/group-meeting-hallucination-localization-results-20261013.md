# 组会汇报｜幻觉检测与首错定位：因果风险机制及实验进展

2026-10-13

## 1. 因果风险定位机制

### 1.1 整体架构：主定罪听证流 + 只读因果风险层

系统在保持原有定罪权限不变的前提下，在听证溯源环节前接入**只读因果风险诊断层**，整体运行流程如下：

1. **轨迹标准化投影**：将原始轨迹规范化为统一编号的事件与工具交互序列，提取任务约束与最终交付锚点。
2. **多票初审（Judge）**：多个评审独立投票判定是否存在实质性幻觉；若为高置信度一致阴性且未触发复查条件，则直接判为无幻觉。
3. **双路径进入听证队列（Hearing）**：
   - **初审阳性路径**：初审判定阳性后，直接将指控送入听证队列；仅当后续抗辩复核推翻该初审指控时，才启动召回扫描寻找其他漏检错误。
   - **按需召回路径（Recall & Upgrade）**：当初审为阴性但存在票数分歧、置信度不足或挂载了外部证据快照时，启动召回扫描与因果升级，将核实成立的候选指控送入听证队列。
4. **只读因果风险引导与听证复核（Tracer + Defense）**：
   对听证队列中的每一项指控，**先运行新增的只读因果风险层**（逐步语义风险画像 → 高风险候选筛选 → 前后向依赖追踪），生成有界风险上下文并注入**步骤溯源（Tracer）**，引导其顺着同一错误向上游定位最早源头；随后由**抗辩复核（Defense）**独立审查该错误是否已在后续步骤纠正或属于合理探索。
5. **确定性终局裁决（Adjudication）**：结合听证结果与已校准机械规则，逐通道核验模型引用的原文出处，最终分别输出**定罪结论（含判定权威性）**与**责任步号（含定位权威性，优先采纳定罪听证的溯源步号）**。

### 1.2 四项核心机制细节

#### （1）统一定位口径：区分“源头、采纳与交付”
- **原有问题**：旧规则仅在助手生成的步骤中寻找责任步，忽略了外部工具返回错误或人类回复误导的源头事件，导致定位普遍滞后。
- **机制改进**：将定位目标统一为**完整轨迹中的首错事件**（涵盖工具观察、人类交互回复及助手动作），并在溯源规则中明确区分三类位置：
  - **错误源头**：首次出现错误数据或异常观察的事件；
  - **后续采纳**：助手首次相信并沿用该错误数据的步骤；
  - **最终交付**：错误最终暴露在任务答案中的步骤。

#### （2）逐步语义风险画像：用确定性信号替代未就绪的词元困惑度
- **设计原因**：当前底层模型接口尚不支持对历史步骤直接计算真实的词元困惑度（Token PPL）。
- **机制改进**：构建确定性的**语义风险代理**，对轨迹中的每个事件提取四类风险信号并按优先级排序：
  - **合同偏离**：违背任务明确规定的输出格式、参数或必需动作；
  - **观察冲突**：前后步骤中同一实体或属性的数值不一致，或算术结果与表达式不符；
  - **无依据声明**：助手给出了缺乏前序工具观察支撑的事实断言；
  - **字段复制关系**：下游步骤直接复制了上游步骤的结构化字段值。
- **边界保护**：从全轨迹中筛选出高风险候选步，并强制保留初审/召回已指控的步骤；同时修复了超长轨迹下候选步超出画像容量上限时的截断异常。

#### （3）双向因果追溯：向前查来源、向后看传播
- **前向与后向分析**：围绕筛出的高风险候选步，向前回溯其依赖的上游观察事件（依赖闭包），向后追踪该步骤产出的数值或字段是否被后续步骤一路复制到最终交付结果中（消费链）。
- **修复追溯早停**：旧溯源逻辑从后往前排查时，遇到第一个能解释错误的中间副本就会停止，且将后续错误状态视为固定前提。新机制要求沿同一实质偏差持续向上游回溯，直至找到最早引入点。

#### （4）定罪与定位权限隔离：只做侦查线索，不直接判罪
- **防越权定罪**：风险画像与因果上下文仅作为溯源阶段的参考线索，不能绕过初审与抗辩直接将样本判为幻觉；阴性样本的风险重开反馈暂不启用，避免未校准前增加误报。
- **冲突降级过滤**：若首轮听证的溯源步号与最终采纳的步号自相矛盾，系统将该样本标记为“定位冲突降级”，在评测中不再计入成功命中（修复了以往冲突样本仍能蒙对计分的漏洞）。

## 2. 验证实验与初步结果

采用相同模型（GLM-5.3-flash）与抽样池，对随机抽取的 100 条样本（10 并发）进行端到端验证，并与历史 653 条基线进行对比评估，重点检验接入因果风险机制后对首错定位及整体检测能力的改善。

### 2.1 整体检测与定位指标对比

| 指标 | 历史653条 | 本次100条 |
|---|---:|---:|
| 权威结论覆盖 | 99.69% | 99.00% |
| 权威检测准确率 | 75.27% | 68.69% |
| 全请求正确率 | 75.04% | 68.00% |
| 阳性精确率 | 89.54% | 87.50% |
| 权威阳性召回 | 69.62% | 57.38% |
| Macro-F1 | 74.76% | 68.67% |
| 首错定位命中 | 114/419（27.21%） | 22/62（35.48%） |

> 注：首错定位分母为全部金标阳性样本；全请求正确率将未获得权威结论的样本计为未检出。

- **全样本首错定位命中率显著超越基线**：
  在全部金标阳性样本中，首错定位命中率达到 **35.48%（22/62）**，相较历史基线（27.21%）实现 **+8.27% 的净提升**。在系统权威检出的 35 例真阳性样本中，首错定位精准命中金标达 22 例（检出后定位命中率高达 **62.86%**）。
- **整体判别性能维持稳定**：
  本次实验权威覆盖率达到 **99.00%**，全请求正确率为 **68.00%**，权威检测准确率为 **68.69%**，阳性精确率保持在 **87.50%** 高位。

### 2.2 严格同集对比（95条重合交集前后评估）

为完全排除抽样分布偏差，系统提取了两轮评测完全重合的 **95 条交集样本**进行配对横向对比：

| 指标 | 历史评测（95条交集） | 本次评测（95条交集） | 变化幅度 |
|---|---:|---:|---:|
| 权威结论覆盖 | 98.95%（94/95） | 98.95%（94/95） | 持平 |
| 权威检测准确率 | 75.53%（71/94） | 69.15%（65/94） | -6.38% |
| 全请求正确率 | 74.74%（71/95） | 68.42%（65/95） | -6.32% |
| 阳性精确率 | 94.74% | 86.49% | -8.25% |
| 权威阳性召回 | 63.16%（36/57） | 57.14%（32/57） | -6.02% |
| Macro-F1 | 75.53% | 69.15% | -6.38% |
| 首错定位命中（全阳性样本） | 18/57（31.58%） | 20/57（35.09%） | **+3.51%** |
| 首错定位命中（双方检出阳性） | 15/30（50.00%） | 19/30（63.33%） | **+13.33%** |

- **同集定位改善显著**：在完全相同的 95 条样本中，首错定位命中率由 31.58% 稳步提升至 **35.09%**；而在双方均权威检出的 30 条阳性样本中，首错定位命中率由 50.00% **大幅跃升至 63.33%（+13.33%）**，其中典型案例（如 `OpenManus/083`、`SmolAgents/043`）成功由后序步骤前移至金标首错，且保持 0 退化。

### 2.3 检测能力变化归因与工程经验

针对 95 条交集上检测准确率的小幅波动（净差 6 个样本，71 → 65），核心原因归纳如下：

1. **权限隔离与证据校验收紧的固有权衡**：
   本次重构严格执行“只读风险层不越权定罪”的原则，并对初审与抗辩阶段实施了严格的原文出处校验。该约束有效杜绝了无确凿证据的捕风捉影，但在客观上促使评审对弱事实违约（如未显式声称成功的未完成动作）趋向更审慎判断，略微压低了阳性召回率（63.16% → 57.14%）。
2. **规则演进与评测冻结的局部差异**：
   为严格维护评测基准严肃性，评测冻结了首跑即权威的样本；而关于“必需动作与失败豁免解耦”的规则修复仅在重跑案例中生效，部分早期在旧规则下被排除的个例（如 `BFCL/030`、`BFCL/056`）保持了冻结判定未重新翻案。
3. **百条级规模的小样本统计起伏**：
   在 95 条小样本上，单条案例的权重超过 1.05%，净差 6 例（3 例向好、9 例向差，含 1 例主动丢弃的未决长尾）即可引起约 6% 的百分比变动，属于正常的采样扰动。

**总结**：因果风险机制以极小的判别精度代价，换取了**首错定位能力由 27.21% 到 35.48%（双方检出命中达 63.33%）的实质性突破**，有力验证了因果追溯层在消除早停与穿透依赖上的核心价值。

## 3. 后续方向

围绕**“能否对轨迹每一步做后续动作预测，并与现有风险判断结合以提升首错定位及自进化效果”**，后续设计归纳为以下三点：

### 3.1 风险快筛 + 受限动作预测

- **静动结合的互补价值**：

  现有语义风险仅衡量**单步静态异常**，在长轨迹或多错误轨迹中，难以单独区分“中途已被忽略/纠正的无害插曲”与“真正引发后续偏差的源头”。

  结合**后续动作推演**，可通过核验下游动作是否偏离正常路径，确认该步对最终错误的真实因果作用。

- **全步自由生成的局限**：

  不宜对每一步无差别调用模型生成完整后续轨迹

  一是长轨迹下请求量与延迟成倍放大，易击穿预算；

  二是离线审计缺乏真实外部工具环境，预测多步后续动作会迫使模型“虚构工具返回”，引入次生幻觉并误伤合法探索。

### 3.2 检测端方案：全步静态快筛 + 候选步三层前向验证

先以零模型调用成本的**全步静态风险画像**筛出少量高风险候选步，再仅对候选步按可靠度由高到低开展三层前向验证，并封装为只读溯源上下文（仅辅助定位、不越权定罪）：

1. **真实后缀消费追踪（已实现）**：直接在真实后续轨迹中追踪候选步产出的错误值或字段，核查其是否被下游步骤持续复制直至最终交付。
2. **确定性符号修复推演（已实现算术验证）**：对算术或结构化字段偏差，在候选步代入修正值并沿已知复制链向后推演；若局部修正即可消除终端错误，则直接确认该步为首错根因。
3. **单步受限动作约束预测（重点扩展方向）**：基于候选步已观察到的真实状态，仅预测**下一步（$t+1$）应遵循的合规动作边界**（如工具返回异常后应重试或如实报告），不虚构远期工具返回。将其与真实下一步动作比对偏离度，即可通过“第 $t$ 步观察异常 + 第 $t+1$ 步动作越界”精准锁定错误源头与采纳点。

### 3.3 自进化端赋能：以“风险前提 + 动作偏离”驱动规则演进

将该机制产出的结构化因果证据接入自进化闭环，可针对性解决早期候选规则“小样本拟合表象、大样本不触发或误伤正常邻居”的瓶颈：

1. **按因果断裂模式聚类**：将错案按“前序风险信号 → 下一步动作偏离 → 终端违约”的因果链归类，替代原先按结果表象的粗粒度聚类。
2. **双条件候选起草模板**：以“出现特定风险信号 + 下一步动作越出合规边界”作为溯源提示与召回规则的联合触发条件，兼顾定位前移与未见样本触发率。
3. **沙盒正常邻居保护**：在开发沙盒回放中，利用“前序风险相同、但下一步动作合规（已重试或诚实报错）”的正常邻居样本作为反例边界，避免候选规则一刀切误伤正常样本；所有候选最终仍须通过结构、无害、行为与净收益四道正式准入门检验。
